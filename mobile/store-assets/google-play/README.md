# Google Play listing assets

- `app-icon-512.png` — 512 × 512 PNG app icon.
- `feature-graphic.jpg` — 1024 × 500 JPEG feature graphic.
- `phone/` — four 1080 × 1920 JPEG screenshots.

The phone images use the existing App Store captures of the shared Flutter UI, fitted to Google Play's 9:16 size while preserving the full screen content.
