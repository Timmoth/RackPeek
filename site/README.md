# RackPeek website

This is a small, static marketing site with a landing page, privacy policy and
support page. It has no build step or package installation.

Open `index.html` directly or serve the `site/` directory with any static web
server. Tailwind's browser build is included locally at `assets/tailwind.js`;
the site does not load CSS frameworks, fonts, scripts or images from a CDN.

The privacy page follows the iOS app policy in `../mobile/privacy-policy.md`.
When app data handling changes, update both copies before publishing.
