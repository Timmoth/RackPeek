Privacy

Privacy policy

RackPeek for iOS is a companion app for a RackPeek server that you choose and operate. This policy describes the app's current data handling.

Effective date: 22 October 2026

Information the app uses

To connect, you enter a RackPeek server address and API key. The app stores these values in iOS secure storage on your device so it can reconnect. The app sends the API key with requests to the server address you entered. Inventory information is received from that server and displayed in the app. Changes you make are sent back to that server.

The RackPeek app publisher does not receive this connection information or inventory through an app-operated service. Your RackPeek server may keep its own logs or inventory data under the configuration and policies set by its operator. Contact that operator with questions about their server.

Network security

Use HTTPS when your server supports it. If you connect over unencrypted HTTP, the API key and inventory traffic may be visible to other systems on that network. Only connect to a server you trust.

Analytics and tracking

The current app source does not include advertising, analytics, or cross-app tracking features. This policy must be reviewed if third-party SDKs or new data-handling features are added.

Your choices

You can disconnect from the server in the app's settings. Disconnecting removes the saved server address and API key from this device. It does not delete data from your RackPeek server; manage server data with the server's own tools.

Children's privacy

RackPeek is a general-purpose infrastructure inventory tool and is not designed for children.

Changes and contact

This policy may be updated when app behavior changes. For privacy questions, contact the app's publisher through the project's public support page: GitHub Issues.
