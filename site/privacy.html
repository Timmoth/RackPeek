Privacy

Privacy policy

RackPeek is a mobile app for documenting infrastructure. This policy describes the app's current data handling on iOS and Android.

Effective date: 22 October 2026

Information the app uses

Inventory data is stored on your device so you can view and edit it offline. When you connect to a RackPeek server, the app also stores the server address and API key in the device's secure storage. The app sends the key with requests to that address, downloads the server inventory, and can upload your local changes when you choose to sync.

The app publisher does not receive your connection information or inventory through an app-operated service. Your RackPeek server may keep its own logs and inventory under the configuration and policies set by its operator. Contact that operator with questions about their server.

Network security

Use HTTPS when your server supports it. If you connect over unencrypted HTTP, the API key and inventory traffic may be visible to other systems on that network. Only connect to a server you trust.

Analytics and tracking

The current app source does not include advertising, analytics, or cross-app tracking features. This policy must be reviewed if third-party SDKs or new data-handling features are added.

Your choices

You can disconnect from the server in the app. Disconnecting removes the saved server address and API key from this device. It does not delete the local inventory or data from your RackPeek server. Manage server data with the server's own tools.

Children's privacy

RackPeek is a general-purpose infrastructure inventory tool and is not designed for children.

Changes and contact

This policy may be updated when app behavior changes. For privacy questions, contact the app's publisher through the project's public support page: GitHub Issues.
