RackPeek support

Need a hand with RackPeek? Start with the documentation. If you still need help, create an issue in the project’s GitHub repository.

Create a GitHub issue ↗Browse the documentation →

What to include

Share what you were trying to do, what happened, and the steps to reproduce it. Include relevant error messages and your RackPeek version. Remove API keys, passwords, public IPs and other private details before posting.

Using the iOS app?

The app connects directly to the RackPeek server you choose. If you have a connection or inventory issue, include whether it happens in the mobile app, web UI or CLI, and check with the server operator if you don't run that server yourself.
